# NovaGrid

**Простая кроссплатформенная программа для работы с таблицами.**
Откройте xls/xlsx/csv на любом устройстве, найдите, отфильтруйте, сложите — без изучения Excel.

> Статус проекта: **Этап 1 «Ядро таблицы» собран** (карточка novagrid-005) — работает живой
> канвас-грид: виртуализация (60 fps на 100k×30), редактирование с IME, выделение с
> Ctrl-несмежными массивами, undo/redo, Alt-выделение с мгновенной суммой, живые метрики
> Σ/n/x̄ в статус-баре. Решения спайка зафиксированы ([docs/SPIKE-1-GRID.md](docs/SPIKE-1-GRID.md)).
> Этап 0 закрыт по каркасу; осталось согласование документации (0.1); GitHub Pages
> заблокирован планом GitHub — см. раздел «CI и GitHub Pages».

## Принципы проекта

Изложены в `promt.txt` и проработаны в документации:

1. **Простота работы** — минимум кнопок, ноль обучения; никаких графиков, диаграмм и сложных вычислений.
2. **Поддержка всех форматов таблиц** — чтение .xlsx, .xls, .csv, .tsv (запись — .xlsx и .csv).
3. **Универсальность платформ** — одно приложение работает на Windows, macOS, Linux, Android и iOS.
4. **Ключевые функции делаются по-настоящему удобными**: поиск, фильтрация правой кнопкой мыши по нескольким ячейкам, большая кнопка суммы, выделение с Ctrl, Alt-выделение с мгновенной суммой, встроенная помощь по формулам.
5. **Приватность** — всё работает локально на устройстве, файлы никуда не отправляются, аккаунт не нужен.

## Технология (кратко)

Веб-приложение **PWA** (устанавливается на любое устройство, работает офлайн) на TypeScript + React с собственным быстрым канвас-гридом. Обоснование и детали — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что уже работает (Этап 1 — ядро таблицы)

Демо-лист в духе сценария ТЗ (фамилии + суммы) засеян при старте; файлы откроются на Этапе 2.

- **Грид**: собственный canvas-грид с виртуализацией — за кадр рисуются только видимые
  ячейки; прокрутка и навигация не проседают на листе 100 000 строк × 30 колонок
  (проверяется e2e-замером кадра; стресс-режим: `npm run dev` → `http://localhost:5173/?stress=100000`).
- **Редактирование**: ввод с клавиатуры сразу с символа, F2 — правка значения, Enter/Tab
  фиксируют и двигают, Escape отменяет; кириллица и IME — нативно (DOM-редактор над канвасом).
- **Выделение (как в привычных сервисах)**: клик, Shift+клик и Shift+стрелки — диапазон,
  **Ctrl+клик — несмежные области одним массивом**, Ctrl+A — весь лист, Esc — снять;
  клик по шапке выделяет колонку/строку.
- **Alt + перетаскивание — мгновенная сумма** (Ф4): оранжевое лассо, Σ появляется у курсора
  сразу, без единого клика; статус-бар живьём показывает `Σ · n · x̄` по выделению.
- **Undo/Redo**: Ctrl+Z / Ctrl+Y (и Ctrl+Shift+Z) — delta-стек по изменённым ячейкам.
- **Горячие клавиши**: стрелки (Ctrl+стрелки — прыжок к краю данных), Home/End, PageUp/Down,
  Delete — очистка выделения, F2, Enter/Tab/Shift-варианты.

## Как ведётся работа

Проектом управляет диспетчер задач (карточки в `CARDS/`, протокол — в `AGENTS.md`). Правила проекта: бэкап через `backup.bat` перед серьёзными изменениями, отчёт в `promt.txt`, коммит после задачи, актуальность README/ROADMAP.

### Синхронизация с GitHub (настроена, карточка novagrid-002)

- Удалённый репозиторий: **https://github.com/summonss7/NovaGrid** (приватный); remote `origin` по HTTPS, рабочая ветка `main`.
- После каждой закрытой задачи делается коммит и автоматический пуш: достаточно `git push` — ветка `main` уже отслеживает `origin/main` (upstream настроен при первом пуше).
- Авторизация не требует ввода пароля: персональный токен пользователя `summonss7` сохранён в Git Credential Manager и `~/.git-credentials`, поэтому `git push` и `git pull` проходят в скриптах и агентах без интерактива.
- Репозиторий приватный до релиза: публикация (переключение в public) запланирована на КТ-5 вместе с v1.0 (см. ROADMAP).

### CI и GitHub Pages (карточка novagrid-003)

- **CI** — [.github/workflows/ci.yml](.github/workflows/ci.yml): на каждый пуш в `main` и на каждый PR выполняется ESLint → typecheck (`tsc`) → юнит-тесты (Vitest) → **e2e (Playwright, Chromium: стартовый экран, фирменные цвета, self-host шрифты)** → сборка (Vite).
- **Деплой** — [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml): на каждый пуш в `main` собирает приложение и публикует на GitHub Pages (Source: GitHub Actions; сборка с относительными путями `base: './'`, поэтому работает из подкаталога `/NovaGrid/`).
- **Сейчас деплой пропускается**: репозиторий приватный, а Pages для приватных репозиториев доступен только на платных планах GitHub (API отвечает «plan does not support»). Workflow сам проверяет доступность Pages и пропускает шаги деплоя с пометкой в логе — рант не краснеет.
- **Как включить Pages** (решение владельца, карточка novagrid-003 заблокирована на этом пункте): перевести репозиторий в public (запланировано на КТ-5 вместе с v1.0) **или** перейти на платный план; затем в Settings → Pages выбрать Source: **GitHub Actions**. После этого деплой пойдёт автоматически на следующий пуш в `main`; адрес сайта: **https://summonss7.github.io/NovaGrid/**.
