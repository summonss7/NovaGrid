# NovaGrid

**Простая кроссплатформенная программа для работы с таблицами.**
Откройте xls/xlsx/ods/csv на любом устройстве, найдите, отфильтруйте, сложите — без изучения Excel.

## Принципы проекта

Изложены в `promt.txt` и проработаны в документации:

1. **Простота работы** — минимум кнопок, ноль обучения; никаких графиков, диаграмм и сложных вычислений.
2. **Поддержка всех форматов таблиц** — чтение .xlsx, .xls, .ods, .csv, .tsv (запись — .xlsx, .csv и зашифрованный снапшот .nvgridx).
3. **Универсальность платформ** — одно приложение работает на Windows, macOS, Linux, Android и iOS.
4. **Ключевые функции делаются по-настоящему удобными**: поиск, фильтрация правой кнопкой мыши по нескольким ячейкам, большая кнопка суммы, выделение с Ctrl, Alt-выделение с мгновенной суммой, встроенная помощь по формулам.
5. **Приватность** — всё работает локально на устройстве, файлы никуда не отправляются, аккаунт не нужен.

## Технология (кратко)

Веб-приложение **PWA** (устанавливается на любое устройство, работает офлайн) на TypeScript + React с собственным быстрым канвас-гридом. Для Windows собрана нативная обёртка **Tauri 2** (Этап 7.5, [docs/WRAPPER.md](docs/WRAPPER.md)). Обоснование и детали — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что уже работает (Этап 7.6 — облачная синхронизация снапшотом .nvgridx)

Из бэклога Этапа 7 («опционально и приватно»), собрано в v1.8.0. Схема
выбрана владельцем из трёх предложенных (файл-снапшот / WebDAV / отложить) —
**снапшот-капсула**: синхронизация любым облачным диском без доверия
провайдеру, без серверов и аккаунтов NovaGrid.

- **Экспорт**: «Сохранить как…» (Ctrl+Shift+S) → формат `.nvgridx` →
  парольная фраза и её повтор. Вся книга — листы, ячейки, стили, кэш чужих
  формул, габариты, имя файла, разделитель CSV — упаковывается в JSON и
  шифруется **AES-256-GCM** (WebCrypto); ключ выводится из фразы
  **PBKDF2-HMAC-SHA256** (310 000 итераций, свежая соль на каждый экспорт).
- **Что видно провайдеру** — только шифротекст: заголовок капсулы
  (магия `NVGRIDX`+версия, соль, IV) и байты GCM; в файле нет ни имён листов,
  ни значений ячеек. Заголовок идёт в AAD — подделка ломает тег.
- **Импорт**: открыть .nvgridx любой точкой входа (кнопка «Открыть»,
  drag&drop, ассоциации обёртки, «Недавние») → диалог спросит фразу;
  неверная фраза — инлайн-ошибка и повтор. Книга ставится на экран с
  исходным именем и именами листов; хэндл/путь не подхватываются, чтобы
  Ctrl+S не затирал капсулу xlsx-байтами.
- **Конфликты версий** решает облако само («побеждает последний», копия
  конфликта остаётся рядом) — слияний в приложении нет, это осознанный
  масштаб схемы А; капсулы независимы от формата .xlsx/.csv.
- **Границы скоупа**: в капсулу не едут фильтры и переопределённые ширины
  колонок (тот же состав, что у автосохранения сессии); забытая фраза —
  данные не восстановить (восстановления нет by design).
- Десктоп-обёртка: нативные диалоги знают фильтр `.nvgridx` (открытие
  и «Сохранить как»); формат локализован ru/en; приём добавлен в справку F1.

## Что уже работает (Этап 7.4 — печатные формы)

Печать браузером из бэклога Этапа 7, собрана в v1.4.0. Канвас не печатается —
по модели книги собирается отдельный печатный DOM:

- **`Ctrl+P` открывает диалог настроек** (на мобильных — пункт «Печать»
  в меню «⋯»): что печатать — видимые строки с учётом фильтров (по умолчанию,
  в подписи живой счётчик «132 из 501») или весь лист; ориентация альбомная
  по умолчанию (книжная — выбором), формат A4/Letter. «Печать…» применяет
  настройки и вызывает системный предпросмотр браузера.
- **Чистая печатная страница**: тулбар, лента фильтров, строка формул, канвас,
  панель листов, статус-бар, мобильная панель, диалоги и тосты на бумаге
  скрыты (`@media print`) — остаются только данные: заголовок «файл · лист»,
  чипы активных фильтров и «Показано N из M» в колонтитуле, таблица.
- **Таблица как в гриде**: заголовки колонок (A, B, C…) и модельные номера
  строк — скрытые фильтром строки не сдвигают нумерацию; заголовки колонок
  повторяются на каждой странице (нативный `thead`), тонкие линии сетки,
  печатный системный шрифт без тяжёлых веб-весов, жирность/выравнивание
  из стилей ячеек переносятся.
- **Числа и даты — форматом текущей локали** интерфейса (10 000 / 10,000;
  11.10.2026 / 10/11/2026); формулы печатаются вычисленными значениями.
- **Границы скоупа** (анти-скоуп CONCEPT §5): без масштабирования по страницам
  Excel-класса; сверх 20 000 строк печать обрезается с честной заметкой
  в колонтитуле (страховка от подвисания вкладки на стресс-листах).
- Прямая печать из меню браузера (мимо диалога) тоже даёт чистую страницу —
  печатный DOM собирается по событию `beforeprint` с последними настройками.
- Локализация ru/en подписей диалога и колонтитула; `Ctrl+P` — в справочнике
  горячих клавиш (F1).

## Что уже работает (Этап 7.5 — десктоп-приложение)

Обёртка Tauri 2 из бэклога Этапа 7, собрана в v1.5.0. Windows-приложение
с теми же возможностями, что и веб-версия, плюс нативная оболочка:

- **Установщик и портабельная сборка** (`npm run desktop:build`):
  `builds/novagrid-<версия>-setup-release.exe` — установка per-user без
  администратора (`%LOCALAPPDATA%\Programs\NovaGrid`, ярлыки «Пуск»/рабочий
  стол, деинсталлятор), рядом — портабельная папка + zip (exe и
  WebView2Loader.dll, запускается без установки). Пререквизиты и протокол —
  [docs/WRAPPER.md](docs/WRAPPER.md). Развёрнутая у владельца копия
  `C:\NovaGrid` при выпуске новой версии обновляется автоматически
  (scripts/deploy-portable.sh, карточка novagrid-021).
- **Файловые ассоциации** (чекбокс установки): NovaGrid появляется
  в «Открыть с помощью» для .xlsx/.xls/.ods/.csv; владелец по умолчанию
  (Excel/LibreOffice) не перехватывается. Двойной клик по книге запускает
  `NovaGrid.exe <путь>` — файл открывается на старте тем же конвейером,
  что и drag-and-drop в браузере.
- **Несколько книг одновременно — каждое окно своя книга** (v1.7,
  novagrid-023): несколько файлов из проводника (одной командой или каждое
  своим запуском), мультивыбор в «Файл → Открыть» и пачка перетащенных
  файлов — первая книга в текущем окне, остальные — в новых окнах;
  перетащенные без пути на диске едут через снимок байтов обёртки.
  В браузере/PWA несколько книг — это вкладки браузера, там поведение
  прежнее (открывается первая).
- **Нативное меню «Файл»**: Открыть/Сохранить/Сохранить как/Печать —
  акселераторы меню шлют события тем же обработчикам, что и горячие клавиши
  веб-части (Ctrl+O/S/Shift+S/P); «Справка» — «О программе» и ссылка на сайт.
- **Системные диалоги** вместо браузерных (rfd): «Открыть книгу»,
  «Сохранить как»; `Ctrl+S` пишет прямо по пути открытого файла.
- **Внешние ссылки** (справка F1 и пр.) открываются в системном браузере.
- **Веб-часть не изменилась**: мост `src/io/desktop.ts` целиком за
  `isDesktop()` (признак `window.__TAURI__`), npm-пакеты `@tauri-apps`
  не подключаются — браузерная сборка и PWA идентичны прежним; в обёртке
  service worker не регистрируется (контент уже внутри exe).
- Dev-режим обёртки — `npm run desktop:dev`: vite devserver + HMR в окне.

- **Контраст WCAG AA в обеих темах**: тёмный набор дизайн-токенов подобран

  `node scripts/contrast-audit.mjs` гоняет два прохода — светлый и тёмный.

## Что уже работает (Этап 7 — найти и заменить)

Единственная функция, отложенная за пределы v1.0 решением планирования
(CONCEPT §6 в.5), — собрана в v1.1.0:

- **Диалог `Ctrl+H`** (кнопка в панели поиска, на мобильных — пункт в «⋯»):
  поля «Найти»/«Заменить на», область «Этот лист / Все листы», параметры
  «учитывать регистр», «ячейка целиком» — те же, что у поиска; открывается
  с запросом открытой панели поиска (Ctrl+F → Ctrl+H — продолжить тем же словом).
- **«Заменить» и «Заменить все»** с живым счётчиком «Найдено: N» / «Заменено: N»;
  Enter/Shift+Enter шагают по совпадениям с автопрокруткой, серия «Заменить»
  проходит каждое совпадение ровно один раз (замена, порождающая новое
  совпадение — «Иван» → «Иванов», — не зацикливается).
- **Undo как в Excel**: все замены идут через delta-историю — один `Ctrl+Z`
  откатывает весь батч «Заменить все»; батч по книге откатывается на всех
  листах разом (сквозная транзакция истории). Ctrl+Z работает и при открытом
  диалоге; Esc закрывает.
- **Формулы**: по умолчанию заменяется вычисленное значение (формула, чей
  результат совпал, становится статикой — как «Заменить: Значения» в Excel);
  галочка «искать в формулах» меняет текст после «=» с последующим пересчётом
  движком. Чужие формулы (∛) не трогаются ни в одном режиме.
- **Фильтры и Σ**: замена уважает фильтры — скрытые строки не трогаются
  (что нашлось, то и заменится), RowLayout пересчитывается после батча
  (строки с новым значением скрываются/показываются по include-фильтру),
  Σ/статус-бар видят новые значения.
- Доступность и локализация: модальный диалог с фокус-трапом, Esc, ARIA
  (как у остальных диалогов), интерфейс ru/en.

## Что уже работает (Этап 4 — формулы и помощь)

- **Формулы (Ф6)**: ячейка начинается с `=` — свой движок считает 33 функции
  (SUM, SUMIF, **SUMIFS**, AVERAGE/AVERAGEIF, COUNT/COUNTA/COUNTBLANK/COUNTIF, MIN, MAX,
  ROUND, ABS, IF, IFS, AND, OR, NOT, CONCAT, LEFT/RIGHT/MID/LEN/TRIM/UPPER/LOWER,
  **VLOOKUP**, DATE, TODAY, YEAR/MONTH/DAY). Разделители аргументов «;» или «,»
  (во втором случае запятая в числе работает десятичной: `1,5`), числа с точкой и запятой,
  адреса `A1`/`$B$2`, диапазоны `A2:C501` и колонки целиком `A:A`, критерии с
  `>`, `>=`, `<>` и джокерами `* ?`, склейка `&`, проценты `10%`.
- **Живой пересчёт (4.2)**: правка ячейки пересчитывает только задетые формулы
  и их цепочку зависимых; циклические ссылки называются по имени.
  Σ в статус-баре, поиск, фильтры и CSV-экспорт видят вычисленные значения.
- **Строка формул (4.3)**: показывает формулу активной ячейки (или значение),
  правится на месте — Enter фиксирует, Esc отменяет.
- **Указание кликами (v1.6, novagrid-020)**: во время ввода «=…» клик по ячейке
  вставляет её адрес на место каретки — `=`, клик по C2, `+`, клик по D2 → `=C2+D2`;
  протяжка мышью — диапазон `C2:C4`. Работает и в редакторе ячейки, и в строке
  формул; фокус не уходит из ввода, правка не фиксируется (как в Excel).
- **Помощь в момент ввода (4.4)**: после «=» — список функций с описаниями
  (Tab подставляет; Enter — после выбора стрелками), внутри вызова — подпись
  аргументов `SUM(число1; [число2]; …)` с выделением текущего. Ошибки — человеческим
  языком прямо в ячейке: «Не хватает закрывающей скобки», «Диапазон A5:A2 записан
  снизу вверх — нужно A2:A5», «Неизвестная функция …».
- **Справочник «?» (4.5)**: кнопка в тулбаре или F1 — карточки всех функций
  с **живыми примерами, посчитанными на вашей таблице** (пустому листу служит
  встроенная мини-таблица), поиск, горячие клавиши и приёмы
  («как отфильтровать по двум колонкам»).
- **Чужие формулы (4.6)**: при открытии .xlsx формула читается вместе с кэшем
  результата Excel; то, что наш движок не считает, показывает последнее значение
  с меткой **«∛ не пересчитывается»** (в ячейке и строке формул) и сохраняется как есть;
  поддерживаемое пересчитывается заново. Экспорт .xlsx пишет `{формула, результат}`,
  CSV — вычисленные значения.

## Что уже работает (Этап 3 — поиск · ПКМ-фильтр · Σ)

Три главные фичи из ТЗ, поверх файлового цикла Этапа 2:

- **Поиск (Ф2)**: поле в тулбаре или `Ctrl+F` — инкрементальный (результаты по мере ввода),
  переключатель «Этот лист / Все листы», подсветка всех совпадений мятным фоном, текущее —
  оранжевая рамка с автопрокруткой, счётчик «12 / 47», навигация `Enter` / `Shift+Enter` /
  `F3` / ▲▼, параметры «учитывать регистр» и «ячейка целиком»; в режиме «Все листы» —
  сгруппированный по листам список результатов с переходом по клику. Скрытые фильтром
  строки не ищутся — подсветка всегда видима.
- **Фильтрация ПКМ (Ф3, ключевая)**: ПКМ по ячейке → «Фильтровать: A = «Иванов»»,
  инверсия «Исключить», добавление значения к фильтру, снятие фильтра колонки и сброс всех,
  копирование ячейки/строки. Несколько фильтров объединяются по «И» — сценарий ТЗ
  «A = Иванов И C = 10000» делается двумя правыми кликами. Фильтрация недеструктивна,
  значения берутся те, на которых нажали, без диалогов.
- **Чипы фильтров и статус**: `[A: Иванов ×] [C: 10000 ×] … [Сбросить всё]` — строка под
  тулбаром; крестик снимает фильтр, клик по чипу открывает меню колонки; статус
  «Показано 132 из 501» на панели листов; отфильтрованные колонки помечены воронкой.
- **Меню колонки ▾** (кнопка в заголовке): сортировка по возрастанию/убыванию видимых
  строк (с подтверждением при первом использовании, отменяется Ctrl+Z; пустые остаются
  в конце, числа сортируются числово), галочки значений с количеством и поиском,
  «(Пустые)», сброс фильтра колонки.
- **Σ (Ф4)**: большая оранжевая кнопка — **автосумма (v1.6, novagrid-020)**: встаньте
  на ячейку-приёмник, нажмите Σ и выделите ячейки мышью или касанием (несмежные —
  через Ctrl) — в приёмник вставится `=СУММ(диапазоны)` и посчитается; подсказка
  «Выберите ячейки…» горит в статус-баре, Esc отменяет, Enter собирает выделение
  Shift+стрелками. Шеврон рядом с Σ открывает карточку метрик выделения
  (Сумма / Кол-во чисел / Кол-во заполненных / Среднее / Мин / Макс; клик по строке
  копирует значение); статус-бар всегда показывает `Σ · n · x̄` — при активных фильтрах
  считаются только видимые строки (как в Excel); **Alt + перетаскивание** — оранжевое
  лассо с суммой крупно в зоне кнопки Σ и меткой у курсора, без единого клика.

## Что уже работает (Этап 2 — файлы)

Полный цикл «открыл → правишь → сохранил» поверх ядра грида Этапа 1:

- **Открытие**: кнопка «Открыть» (Ctrl+O), перетаскивание файла в окно, карточки демо-фикстур
  на стартовом экране. Форматы: `.xlsx`/`.xlsm` (ExcelJS — значения, кэш формул, стили:
  жирность/заливка/выравнивание/цвет), `.xls` (SheetJS), `.ods` (SheetJS, значения:
  листы книги → вкладки, даты — ISO; стили ODS не переносятся), `.csv`/`.tsv` —
  с автоопределением
  разделителя (`;`, `,`, таб — по содержимому вне кавычек) и кодировки (UTF-8/UTF-16 по BOM,
  далее строгий UTF-8 → Windows-1251). Парсинг — в **Web Worker**: интерфейс не замирает.
- **Вкладки листов**: переключение, переименование (двойной клик), добавление (+),
  дублирование и удаление с подтверждением (меню ПКМ по вкладке); имена — по правилам Excel.
- **Сохранение**: «Сохранить» (Ctrl+S) — на Chromium-десктопе пишет прямо в открытый файл
  (File System Access), «Сохранить как…» (Ctrl+Shift+S) — выбор имени и формата
  (.xlsx со стилями / .csv активного листа с выбором разделителя); на Firefox/Safari/мобильных —
  скачивание файла. `.xls` сохраняется как `.xlsx` (старый формат записи не
  гарантируется); `.ods` — тоже как `.xlsx` (прямой записи .ods в NovaGrid нет,
  заметка видна в диалоге).
- **Автосохранение сессии** (Dexie/IndexedDB, дебаунс 1 с + сброс при закрытии вкладки):
  после краша/закрытия книга восстанавливается одним кликом из «Недавних» на стартовом экране.
- **«Недавние»: и файлы, и сессии** (novagrid-022): каждый открытый файл сразу попадает
  в список на стартовом экране — последние открытые сверху, повторное открытие поднимает
  запись наверх. Клик переоткрывает сам файл: в десктоп-обёртке — по пути с диска,
  в Chromium — через File System Access (с запросом разрешения), иначе — из локального
  снимка (файлы ≤16 МБ; большие — только именем в списке). Если сессия с правками свежее
  открытия, клик восстановит сессию — несохранённые правки не теряются.
- **Фикстуры** (`public/fixtures/`, генерируются `node scripts/make-fixtures.mjs`):
  демо-книга сценария ТЗ (2 листа, ровно 132 строки «Иванов + 10 000» под сценарий фильтрации),
  стресс-файл 100 000 строк CSV, небольшой `.xls`, двухстраничный `ods-book.ods`
  (числа/текст/даты) и книга формул `formula-book.xlsx`
  (свои SUM/AVERAGE + чужая SUMPRODUCT для метки «∛»).

Ограничения v1 (сознательные, см. CONCEPT Ф1): полная реализация формул Excel не ставится
целью — свой движок на ~30 частых функций, остальное читается кэшем значения с меткой
«∛ не пересчитывается» и сохраняется как есть (Этап 4); макросы `.xlsm` не сохраняются;
объединённые ячейки читаются как значение левой ячейки; стили переносятся только для `.xlsx`
(`.xls` и `.ods` читаются значениями); прямой записи `.ods` нет — «Сохранить как .xlsx/.csv».

## Как ведётся работа

Проектом управляет диспетчер задач (карточки в `CARDS/`, протокол — в `AGENTS.md`). Правила проекта: бэкап через `backup.bat` перед серьёзными изменениями, отчёт в `CHANGELOG.md` (дата-время начала и окончания работы), коммит после задачи, актуальность README/ROADMAP, при выпуске новой версии — автоматическое обновление развёрнутой копии `C:\NovaGrid` (см. [docs/WRAPPER.md](docs/WRAPPER.md)).

### Синхронизация с GitHub (настроена, карточка novagrid-002)

- Удалённый репозиторий: **https://github.com/summonss7/NovaGrid** (приватный); remote `origin` по HTTPS, рабочая ветка `main`.
- После каждой закрытой задачи делается коммит и автоматический пуш: достаточно `git push` — ветка `main` уже отслеживает `origin/main` (upstream настроен при первом пуше).
- Авторизация не требует ввода пароля: персональный токен пользователя `summonss7` сохранён в Git Credential Manager и `~/.git-credentials`, поэтому `git push` и `git pull` проходят в скриптах и агентах без интерактива.
- Репозиторий приватный до релиза: публикация (переключение в public) запланирована на КТ-5 вместе с v1.0 (см. ROADMAP).

### CI и GitHub Pages (карточка novagrid-003)

- **CI** — [.github/workflows/ci.yml](.github/workflows/ci.yml): на каждый пуш в `main` и на каждый PR выполняется ESLint → typecheck (`tsc`) → юнит-тесты (Vitest) → **e2e (Playwright, матрица Этапа 6.4: Chromium — полный набор, включая сценарий КТ-3 «Иванов+10000 → 132 строки → Σ», стресс 100k, формулы, доступность, локализацию; Firefox и WebKit — смок-сценарии ТЗ; Android-эмуляция Pixel 7 — мобильный сценарий касаниями)** → сборка (Vite).
- **Деплой** — [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml): на каждый пуш в `main` собирает приложение и публикует на GitHub Pages (Source: GitHub Actions; сборка с относительными путями `base: './'`, поэтому работает из подкаталога `/NovaGrid/`).
- **Сейчас деплой пропускается**: репозиторий приватный, а Pages для приватных репозиториев доступен только на платных планах GitHub (API отвечает «plan does not support»). Workflow сам проверяет доступность Pages и пропускает шаги деплоя с пометкой в логе — рант не краснеет.
- **Как включить Pages** (решение владельца; v1.0 готова к публикации — детали в [docs/RELEASE-V1.0.md](docs/RELEASE-V1.0.md)): перевести репозиторий в public **или** перейти на платный план; затем в Settings → Pages выбрать Source: **GitHub Actions**. После этого деплой пойдёт автоматически на следующий пуш в `main`; адрес сайта: **https://summonss7.github.io/NovaGrid/**.
