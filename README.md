# NovaGrid

**Простая кроссплатформенная программа для работы с таблицами.**
Откройте xls/xlsx/ods/csv/док (Word) на любом устройстве, найдите, отфильтруйте, сложите — без изучения Excel.

> **English:** NovaGrid is a simple cross-platform spreadsheet app — open
> xls/xlsx/ods/csv/Word docs on desktop, web and Android; search, filter and sum without
> learning Excel. One codebase (Tauri 2 + React + Rust) for every platform.
> A portfolio project of the human + AI freelance duo —
> [duet.barter.pp.ua](https://duet.barter.pp.ua).

> Статус проекта: **v1.31.0** — документы Word и системные ассоциации
> файлов (карточка novagrid-068): **.docx/.doc открываются сеткой** —
> таблицы документа становятся листами («Таблица 1…», объединения ячеек
> и базовое оформление переносятся), текст вне таблиц — листом «Текст»;
> меню то же, формул в Word-документах нет — формат только для чтения,
> «Сохранить как…» конвертирует в .xlsx (как у .xls). Система теперь
> предлагает NovaGrid в «Открыть с помощью» для таблиц и Word-документов:
> Windows — установщик регистрирует .docx/.doc (плюс прежние xlsx/xls/
> ods/csv), Android — intent-filter на Excel/Word/CSV: файл из проводника
> или почты открывается в NovaGrid напрямую (мост Kotlin→JS→Rust).

## Принципы проекта

Изложены в `promt.txt` (локальный замороженный архив, в репозиторий не входит) и проработаны в документации:

1. **Простота работы** — минимум кнопок, ноль обучения; никаких графиков, диаграмм и сложных вычислений.
2. **Поддержка всех форматов таблиц** — чтение .xlsx, .xls, .ods, .csv, .tsv и таблиц из Word .docx/.doc (запись — .xlsx, .ods, .csv и зашифрованный снапшот .nvgridx).
3. **Универсальность платформ** — одно приложение работает на Windows, macOS, Linux, Android и iOS.
4. **Ключевые функции делаются по-настоящему удобными**: поиск, фильтрация правой кнопкой мыши по нескольким ячейкам, большая кнопка суммы, выделение с Ctrl, Alt-выделение с мгновенной суммой, встроенная помощь по формулам.
5. **Приватность** — всё работает локально на устройстве, файлы никуда не отправляются, аккаунт не нужен.

## Что уже работает (Этап 7.6 — облачная синхронизация снапшотом .nvgridx)

Из бэклога Этапа 7 («опционально и приватно»), собрано в v1.8.0. Схема
выбрана владельцем из трёх предложенных (файл-снапшот / WebDAV / отложить) —
**снапшот-капсула**: синхронизация любым облачным диском без доверия
провайдеру, без серверов и аккаунтов NovaGrid.

- **Экспорт**: «Сохранить как…» (Ctrl+Shift+S) → формат `.nvgridx` →
  парольная фраза и её повтор. Вся книга — листы, ячейки, стили, кэш чужих
  формул, габариты, имя файла, разделитель CSV — упаковывается в JSON и
  шифруется **AES-256-GCM** (WebCrypto); ключ выводится из фразы
  **PBKDF2-HMAC-SHA256** (310 000 итераций, свежая соль на каждый экспорт).
- **Что видно провайдеру** — только шифротекст: заголовок капсулы
  (магия `NVGRIDX`+версия, соль, IV) и байты GCM; в файле нет ни имён листов,
  ни значений ячеек. Заголовок идёт в AAD — подделка ломает тег.
- **Импорт**: открыть .nvgridx любой точкой входа (кнопка «Открыть»,
  drag&drop, ассоциации обёртки, «Недавние») → диалог спросит фразу;
  неверная фраза — инлайн-ошибка и повтор. Книга ставится на экран с
  исходным именем и именами листов; хэндл/путь не подхватываются, чтобы
  Ctrl+S не затирал капсулу xlsx-байтами.
- **Конфликты версий** решает облако само («побеждает последний», копия
  конфликта остаётся рядом) — слияний в приложении нет, это осознанный
  масштаб схемы А; капсулы независимы от формата .xlsx/.csv.
- **Границы скоупа**: в капсулу не едут фильтры и переопределённые ширины
  колонок (тот же состав, что у автосохранения сессии); забытая фраза —
  данные не восстановить (восстановления нет by design).
- Десктоп-обёртка: нативные диалоги знают фильтр `.nvgridx` (открытие
  и «Сохранить как»); формат локализован ru/en; приём добавлен в справку F1.

## Что уже работает (Этап 7.4 — печатные формы)

Печать браузером из бэклога Этапа 7, собрана в v1.4.0. Канвас не печатается —

  по умолчанию (книжная — выбором), формат A4/Letter. «Печать…» применяет
  настройки и вызывает системный предпросмотр браузера.
- **Чистая печатная страница**: тулбар, лента фильтров, строка формул, канвас,
  панель листов, статус-бар, мобильная панель, диалоги и тосты на бумаге

  строк — скрытые фильтром строки не сдвигают нумерацию; заголовки колонок
  повторяются на каждой странице (нативный `thead`), тонкие линии сетки,
  печатный системный шрифт без тяжёлых веб-весов, жирность/выравнивание
  из стилей ячеек переносятся.
- **Числа и даты — форматом текущей локали** интерфейса (10 000 / 10,000;
  11.10.2026 / 10/11/2026); формулы печатаются вычисленными значениями.
- **Границы скоупа** (анти-скоуп CONCEPT §5): без масштабирования по страницам
  Excel-класса; сверх 20 000 строк печать обрезается с честной заметкой
  в колонтитуле (страховка от подвисания вкладки на стресс-листах).
- Прямая печать из меню браузера (мимо диалога) тоже даёт чистую страницу —
  печатный DOM собирается по событию `beforeprint` с последними настройками.
- Локализация ru/en подписей диалога и колонтитула; `Ctrl+P` — в справочнике
  горячих клавиш (F1).

  поля «Найти»/«Заменить на», область «Этот лист / Все листы», параметры
  «учитывать регистр», «ячейка целиком» — те же, что у поиска; открывается
  с запросом открытой панели поиска (Ctrl+F → Ctrl+H — продолжить тем же словом).
- **«Заменить» и «Заменить все»** с живым счётчиком «Найдено: N» / «Заменено: N»;
  Enter/Shift+Enter шагают по совпадениям с автопрокруткой, серия «Заменить»
  проходит каждое совпадение ровно один раз (замена, порождающая новое
  совпадение — «Иван» → «Иванов», — не зацикливается).
- **Undo как в Excel**: все замены идут через delta-историю — один `Ctrl+Z`
  откатывает весь батч «Заменить все»; батч по книге откатывается на всех
  листах разом (сквозная транзакция истории). Установка и снятие фильтров —
  тоже шаги истории (novagrid-071). Ctrl+Z работает и при открытом
  диалоге; Esc закрывает.
- **Формулы**: по умолчанию заменяется вычисленное значение (формула, чей
  результат совпал, становится статикой — как «Заменить: Значения» в Excel);
  галочка «искать в формулах» меняет текст после «=» с последующим пересчётом
  движком. Чужие формулы (∛) не трогаются ни в одном режиме.
- **Фильтры и Σ**: замена уважает фильтры — скрытые строки не трогаются
  (что нашлось, то и заменится), RowLayout пересчитывается после батча
  (строки с новым значением скрываются/показываются по include-фильтру),
  Σ/статус-бар видят новые значения.
- Доступность и локализация: модальный диалог с фокус-трапом, Esc, ARIA
  (как у остальных диалогов), интерфейс ru/en.

## Что уже работает (Этап 4 — формулы и помощь)

- **Формулы (Ф6)**: ячейка начинается с `=` — свой движок считает 33 функции
  (SUM, SUMIF, **SUMIFS**, AVERAGE/AVERAGEIF, COUNT/COUNTA/COUNTBLANK/COUNTIF, MIN, MAX,
  ROUND, ABS, IF, IFS, AND, OR, NOT, CONCAT, LEFT/RIGHT/MID/LEN/TRIM/UPPER/LOWER,
  **VLOOKUP**, DATE, TODAY, YEAR/MONTH/DAY). Разделители аргументов «;» или «,»
  (во втором случае запятая в числе работает десятичной: `1,5`), числа с точкой и запятой,
  адреса `A1`/`$B$2`, диапазоны `A2:C501` и колонки целиком `A:A`, критерии с
  `>`, `>=`, `<>` и джокерами `* ?`, склейка `&`, проценты `10%`.
- **Живой пересчёт (4.2)**: правка ячейки пересчитывает только задетые формулы
  и их цепочку зависимых; циклические ссылки называются по имени.
  Σ в статус-баре, поиск, фильтры и CSV-экспорт видят вычисленные значения.
- **Даты в арифметике (v1.21, novagrid-038)**: дата в ячейке («2026-10-27» или
  «27.10.2026», как пишет импорт) — полноценный операнд: `=A1+1` — следующий
  календарный день, `=A1-7` — неделя назад, `=A1-B1` — сколько дней между
  датами; переходы месяца/года и високосность честные, время «10:30» в дате
  сохраняется, формат результата повторяет формат операнда. YEAR/MONTH/DAY
  понимают оба формата.
- **Строка формул (4.3)**: показывает формулу активной ячейки (или значение),
  правится на месте — Enter фиксирует, Esc отменяет.
- **Указание кликами (v1.6, novagrid-020)**: во время ввода «=…» клик по ячейке
  вставляет её адрес на место каретки — `=`, клик по C2, `+`, клик по D2 → `=C2+D2`;
  протяжка мышью — диапазон `C2:C4`. Работает и в редакторе ячейки, и в строке
  формул; фокус не уходит из ввода, правка не фиксируется (как в Excel).
- **Помощь в момент ввода (4.4)**: после «=» — список функций с описаниями
  (Tab подставляет; Enter — после выбора стрелками), внутри вызова — подпись
  аргументов `SUM(число1; [число2]; …)` с выделением текущего. Ошибки — человеческим
  языком прямо в ячейке: «Не хватает закрывающей скобки», «Диапазон A5:A2 записан
  снизу вверх — нужно A2:A5», «Неизвестная функция …».
- **Справочник «?» (4.5)**: кнопка в тулбаре или F1 — карточки всех функций
  с **живыми примерами, посчитанными на вашей таблице** (пустому листу служит
  встроенная мини-таблица), поиск, горячие клавиши и приёмы
  («как отфильтровать по двум колонкам»).
- **Чужие формулы (4.6)**: при открытии .xlsx формула читается вместе с кэшем
  результата Excel; то, что наш движок не считает, показывает последнее значение
  с меткой **«∛ не пересчитывается»** (в ячейке и строке формул) и сохраняется как есть;
  поддерживаемое пересчитывается заново. Экспорт .xlsx пишет `{формула, результат}`,
  CSV — вычисленные значения.

целью — свой движок на ~30 частых функций, остальное читается кэшем значения с меткой
«∛ не пересчитывается» и сохраняется как есть (Этап 4); макросы `.xlsm` не сохраняются;
объединённые ячейки читаются и показываются объединёнными (запись объединений
и границ ячеек в файл — карточка novagrid-050); стили переносятся только для `.xlsx`
(`.xls` читается значениями, `.ods` — значениями и формулами без стилей); прямой записи
`.ods` нет — «Сохранить как .xlsx/.csv».

## Что уже работает (Этап 1 — ядро таблицы)

- **Грид**: собственный canvas-грид с виртуализацией — за кадр рисуются только видимые
  ячейки; прокрутка и навигация не проседают на листе 100 000 строк × 30 колонок
  (проверяется e2e-замером кадра; стресс-режим: `npm run dev` → `http://localhost:5173/?stress=100000`).
- **Ширины колонок (v1.6, novagrid-020; предел 1000 px — v1.18, novagrid-035)**:
  границу в шапке колонки можно тащить
  мышью — колонка делается шире или уже (32–1000 px, курсор «↔» у границы),
  соседние сдвигаются; ширины помнятся по вкладкам и масштабируются вместе
  с зумом, вытягивание до стандартной ширины сбрасывает переопределение.
- **Автоширина колонок по тексту (novagrid-067)**: галочка «Колонки по
  тексту» в меню «Вид» — каждая колонка встаёт по самому широкому тексту в
  ней (формулы — по вычисленному значению, формат числа учитывается, пол
  32 px), очень широкий текст ограничен потолком ~220 символов; режим
  живёт в настройках вида (переживает перезагрузку), в нём ручные ширины и
  перетаскивание границ не действуют — выключение возвращает ручные
  ширины как были; автовысоты переноса и зум считаются от фактических
  ширин, объединённые ячейки ширину колонок не растят.
- **Редактирование**: ввод с клавиатуры сразу с символа, F2 — правка значения, Enter/Tab
  фиксируют и двигают, Escape отменяет; кириллица и IME — нативно (DOM-редактор над канвасом).
- **Объединение ячеек (v1.26, novagrid-047)**: «Объединить ячейки» и «Отменить
  объединение ячеек» в панели форматирования и в меню ПКМ — как в Excel:
  значение остаётся в левой верхней ячейке, при потере данных спрашивает
  подтверждение; объединённая ячейка рисуется одной областью (текст и фон —
  левой верхней), клик по скрытой части выбирает угол, Tab/Enter/стрелки
  перепрыгивают объединение целиком, копирование/фильтры/поиск скрытых ячеек
  не видят; вставка/удаление строк и колонок сдвигает и режет объединения
  вместе с данными, Ctrl+Z — одной транзакцией; mergeCells импортируются из
  .xlsx/.xls/.ods, объединения живут в сессии и капсуле .nvgridx
  (сохранение в файл — novagrid-050).
- **Перенос текста в ячейке (v1.26, novagrid-048)**: кнопка «Перенос текста»
  в панели форматирования — текст ячейки переносится по словам под ширину
  колонки, высота строки авто-растёт под число строк (как в Excel), текст
  идёт от верхнего края; слово шире ячейки ломится по символам, явные
  переводы строки дают свои абзацы. Смена ширины колонки и масштаба
  пересчитывает перенос и высоту; сочетается с выравниванием (по строкам),
  форматом числа (переносится отображаемое значение) и стилями; повторный
  клик снимает перенос, Ctrl+Z — одной транзакцией; объединённые ячейки
  переносят текст по всей своей площади без автовысоты. Перенос живёт в
  сессии и капсуле .nvgridx (сохранение в файл — novagrid-050).
- **Границы ячеек (v1.26, novagrid-049)**: выпадающая кнопка «Границы» в панели
  форматирования — все / внешние / верхняя / нижняя / левая / правая / убрать
  (как в Excel), применяется ко всему выделению (у каждой несмежной области —
  свой периметр), стороны дописываются к уже стоящим; линии рисуются в общем
  проходе кадра, общие стороны соседних ячеек не двоятся; периметр объединённой
  ячейки компонуется из краёв её ячеек; вставка/удаление строк и колонок
  сдвигает границы вместе с контентом, «Очистить формат» снимает и их,
  Ctrl+Z — одной транзакцией. Границы живут в сессии и капсуле .nvgridx
  (сохранение в файл — novagrid-050).
- **Подсветка ссылок формулы (v1.24, novagrid-041)**: при правке ячейки с формулой
  (F2, ввод «=» или правка в строке формул) ячейки-источники обводятся цветными
  рамками с лёгкой заливкой — каждая ссылка своим цветом по кругу палитры
  (синий, фиолетовый, оранжевый, бирюзовый, розовый, лавандовый), диапазоны и
  целые колонки (A:A) — блоком; подсветка живая, на каждое нажатие при наборе,
  Esc её гасит.
- **Форматирование ячеек (v1.22, novagrid-039)**: панель над таблицей — выбор шрифта
  (Open Sans / Montserrat) и размера (8–16 pt, «Авто» — стандарт грида), кнопки
  **Ж / К / Ч** (или Ctrl+B / Ctrl+I / Ctrl+U — как в Excel), **цвет текста** и
  **заливка ячейки** (палитра ходовых цветов + «Свой цвет…» системным пикером,
  «Авто»/«Нет заливки» снимают), «Очистить формат» — ластик всего сразу. Всё
  применяется ко всему выделению (диапазон, несмежные области, целые строки/колонки),
  кнопки показывают состояние активной ячейки, каждая правка — одна транзакция
  Ctrl+Z; значения ячеек не трогаются. Стили сохраняются в .xlsx (включая курсив,
  подчёркивание, шрифт и размер), остаются в автосохранении сессии и капсуле
  .nvgridx, читаются обратно из файлов Excel.
- **Выделение (как в привычных сервисах)**: клик, Shift+клик и Shift+стрелки — диапазон
  (растяжение от движущегося конца, якорь — активная ячейка; v1.9),
  **Ctrl+клик — несмежные области одним массивом**, Ctrl+A — весь лист, Esc — снять;
  клик по шапке выделяет колонку/строку, **протяжка от номера строки/заголовка
  колонки выделяет несколько строк/колонок целиком** (v1.21) — нажали и тянете
  вниз/вверх, как в Excel; **Ctrl+C — копировать выделенный диапазон в буфер**
  (вычисленные значения, колонки через таб, строки через перевод — вставляется в Excel/Таблицы; v1.9),
  **Ctrl+V — вставить блоком от активной ячейки** (Excel-совместимый TSV, в том числе
  из другого окна NovaGrid; границы листа растут, один Ctrl+Z откатывает; v1.10),
  **Ctrl+X — вырезать выделение** (блок в буфер, ячейки очищаются одной транзакцией; v1.15).
- **Пустое место для вставки** (v1.15): за данными всегда видны пустые строки и колонки —
  у открытой таблицы границы листа уходят за контент (запас 50 строк × 10 колонок),
  а прокрутка к правому/нижнему краю расширяет лист дальше — скопированный блок
  всегда есть куда вставить. Предел роста — размеры листа Excel .xlsx.
  **Сетка до края окна** (v1.18, novagrid-035): если логическая граница листа
  не докрывает окно (узкий лист при отдалённом зуме, широкий монитор), линии
  сетки и буквы колонок рисуются дальше — виртуальное продолжение до края,
  как в Excel: таблица не выглядит «закончившейся» на полпути.
- **Alt + перетаскивание — мгновенная сумма** (Ф4): оранжевое лассо, Σ появляется у курсора
  сразу, без единого клика; статус-бар живьём показывает `Σ · n · x̄` по выделению.
- **Undo/Redo**: Ctrl+Z / Ctrl+Y (и Ctrl+Shift+Z) — delta-стек по изменённым ячейкам.
- **Горячие клавиши**: стрелки (Ctrl+стрелки — прыжок к краю данных; Shift+стрелки —
  растянуть выделение), Home/End, **Ctrl+Home / Ctrl+End — начало таблицы (A1) /
  последняя ячейка листа** (v1.11), PageUp/Down, Delete — очистка выделения, F2,
  Enter/Tab/Shift-варианты, Ctrl+C — копировать выделение в буфер,
  Ctrl+V — вставить блоком от активной ячейки, Ctrl+X — вырезать выделение (v1.15),
  **Ctrl+B / Ctrl+I / Ctrl+U — жирный / курсив / подчёркнутый всему выделению (v1.22)**.
- **Прокрутка таблицы** (v1.11): колесо мыши и всегда видимые полосы прокрутки
  у правого и нижнего краёв таблицы (классический режим в цветах темы — нативные
  полосы Windows 11 автоскрываются, таблица выглядела непрокручиваемой);
  на тач-устройствах — нативный жест-пан и пинч-зум.

## Как ведётся работа

Проектом управляет диспетчер задач (карточки в локальной папке `CARDS/`, протокол — в `AGENTS.md`; `promt.txt` и `CARDS/` — внутренние документы, в репозиторий не входят). Правила проекта: бэкап через `backup.bat` перед серьёзными изменениями, отчёт в `CHANGELOG.md` (дата-время начала и окончания работы), коммит после задачи, актуальность README/ROADMAP, при выпуске новой версии — автоматическое обновление развёрнутой копии `C:\NovaGrid` (см. [docs/WRAPPER.md](docs/WRAPPER.md)).

### Синхронизация с GitHub (настроена, карточка novagrid-002)

- Удалённый репозиторий: **https://github.com/summonss7/NovaGrid** (приватный); remote `origin` по HTTPS, рабочая ветка `main`.
- После каждой закрытой задачи делается коммит и автоматический пуш: достаточно `git push` — ветка `main` уже отслеживает `origin/main` (upstream настроен при первом пуше).
- Авторизация не требует ввода пароля: персональный токен пользователя `summonss7` сохранён в Git Credential Manager и `~/.git-credentials`, поэтому `git push` и `git pull` проходят в скриптах и агентах без интерактива.
- Репозиторий приватный до релиза: публикация (переключение в public) запланирована на КТ-5 вместе с v1.0 (см. ROADMAP).

### CI и GitHub Pages (карточка novagrid-003)

- **CI** — [.github/workflows/ci.yml](.github/workflows/ci.yml): на каждый пуш в `main` и на каждый PR выполняется ESLint → typecheck (`tsc`) → юнит-тесты (Vitest) → **e2e (Playwright, матрица Этапа 6.4: Chromium — полный набор, включая сценарий КТ-3 «Иванов+10000 → 132 строки → Σ», стресс 100k, формулы, доступность, локализацию; Firefox и WebKit — смок-сценарии ТЗ; Android-эмуляция Pixel 7 — мобильный сценарий касаниями)** → сборка (Vite).
- **Деплой** — [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml): на каждый пуш в `main` собирает приложение и публикует на GitHub Pages (Source: GitHub Actions; сборка с относительными путями `base: './'`, поэтому работает из подкаталога `/NovaGrid/`).
- **Сейчас деплой пропускается**: репозиторий приватный, а Pages для приватных репозиториев доступен только на платных планах GitHub (API отвечает «plan does not support»). Workflow сам проверяет доступность Pages и пропускает шаги деплоя с пометкой в логе — рант не краснеет.
- **Как включить Pages** (решение владельца; v1.0 готова к публикации — детали в [docs/RELEASE-V1.0.md](docs/RELEASE-V1.0.md)): перевести репозиторий в public **или** перейти на платный план; затем в Settings → Pages выбрать Source: **GitHub Actions**. После этого деплой пойдёт автоматически на следующий пуш в `main`; адрес сайта: **https://summonss7.github.io/NovaGrid/**.
