# NovaGrid v1.1 — Релизные заметки

Дата: 2026-10-10 · Версия: 1.1.0 (package.json) · Этап 7, первый пункт бэклога
(карточка novagrid-013; основание — CONCEPT §6 вопрос 5: «найти и заменить»
перенесена из v1.0 в v1.1 решением планирования).

## Что вошло в v1.1.0

Единственная функция из задуманного, официально отложенная за пределы v1.0, —
**«Найти и заменить» (Ctrl+H)**:

- **Диалог `Ctrl+H`** из любого места книги; кнопка в панели поиска и пункт
  в мобильном меню «⋯». Открывается с запросом открытой панели поиска
  (Ctrl+F → Ctrl+H — продолжить тем же словом); повторное открытие помнит
  прошлый запрос. Модальный, как остальные диалоги: фокус-трап, Esc, ARIA.
- **Поля и параметры**: «Найти»/«Заменить на», область «Этот лист /
  Все листы», «учитывать регистр», «ячейка целиком» — те же опции, что у
  поиска (Этап 3.1, core/search переиспользован).
- **«Заменить» и «Заменить все»**: живой счётчик «Найдено: N» /
  «Заменено: N»; Enter/Shift+Enter шагают по совпадениям с автопрокруткой;
  серия «Заменить» проходит каждое совпадение ровно один раз — замена,
  порождающая новое совпадение («Иван» → «Иванов»), не зацикливается.
- **Undo как в Excel**: все замены идут через delta-историю — один Ctrl+Z
  откатывает весь батч «Заменить все». Батч по книге — сквозная транзакция
  (метка `group` в HistoryEntry): один Ctrl+Z возвращает замены на всех
  листах разом, redo возвращает обратно целиком. Ctrl+Z/Ctrl+Y работают и
  при открытом диалоге; в текстовых полях диалога — нативный undo ввода.
- **Формулы**: по умолчанию заменяется вычисленное значение — формула, чей
  результат совпал, становится статическим значением (как «Заменить:
  Значения» в Excel). Галочка «искать в формулах» заменяет текст после «=»
  с последующим пересчётом движком (Этап 4) — формула остаётся формулой.
  **Чужие формулы (∛) не трогаются ни в одном режиме** — кэш из файла
  сохраняется, формула не ломается.
- **Фильтры и Σ**: замена уважает фильтры — скрытые строки не трогаются
  (WYSIWYG: что нашлось, то и заменится), счётчик совпадений согласован
  с заменой. RowLayout пересчитывается после батча — include-фильтр скрывает
  строки с новым значением, Ctrl+Z возвращает видимость. Σ/статус-бар видят
  новые значения.
- **Локализация**: словари ru/en (src/i18n), формат чисел счётчика за языком
  интерфейса.

## Архитектура (кратко)

- `src/core/replace.ts` — движок: `replaceCellRaw` (одна ячейка, режимы
  значений/формул), `replaceHitsInSheet`/`replaceHitsInBook` (счётчик
  согласован с заменой), `replaceAllInSheet` (батч изменений в порядке
  строка→колонк с учётом видимости строк).
- `src/ui/ReplaceDialog.tsx` — диалог + `ReplaceHost` (глобальный Ctrl+H и
  undo/redo при открытом диалоге).
- `src/core/store.ts` — состояние `replace` и действия; undo/redo переведены
  на `applyHistoryEntries` со сквозными транзакциями по метке `group`
  (`src/core/history.ts`).
- `src/grid/testHook.ts` — `replaceInfo()` для e2e (зеркало `searchInfo`).

## Проверка релиза

- lint ✓ · typecheck ✓ · build ✓ (PWA, precache 20 файлов)
- **181 юнит-тест ✓** (в том числе 15 новых: движок замены — подстрока/
  регистр/целость/формулы/чужие формулы/фильтры/пустые случаи; стор —
  батч на листе и по книге, один Ctrl+Z, серия «Заменить», фильтры
  с RowLayout, наследование запроса поиска).
- **56 e2e ✓** (47 прежних + 9 новых tests/replace.spec.ts): сценарий
  готовности карточки «нашёл → заменил все → значения обновились →
  Ctrl+Z вернул всё» — на листе и по книге (второй лист добавляется
  кнопкой «+», один Ctrl+Z возвращает оба листа); плюс серия «Заменить»,
  регистр/«ячейка целиком», режим формул с пересчётом (значение↔формула),
  фильтры (замена скрывает строки под include-фильтром, Ctrl+Z возвращает),
  Σ/статус-бар видят новые значения. Во всех браузерах матрицы
  (Chromium полный, Firefox/WebKit смок, Android-эмуляция) зелёные.
- Мобильный путь: пункт «Найти и заменить» в меню «⋯» тулбара.
