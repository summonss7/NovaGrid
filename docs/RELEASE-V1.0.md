# NovaGrid v1.0 — Релизные заметки

Дата: 2026-10-09 · Версия: 1.0.0 (package.json) · Этап 6 «Полировка и релиз v1.0»
(карточка novagrid-010, docs/CREATION-MAP.md §Этап 6).

## Что вошло в v1.0 (Этапы 0–6)

- **Таблица**: собственный канвас-грид — 60 fps на 100k×30, редактирование
  (F2/Tab/Enter/Esc, IME/кириллица), выделение с Ctrl-несмежными массивами,
  undo/redo, Alt-выделение с живой суммой у курсора.
- **Файлы**: чтение .xlsx/.xlsm (со стилями), .xls, .csv/.tsv (авто-детект
  разделителя и кодировки UTF-8/Windows-1251); вкладки листов; сохранение
  .xlsx со стилями и .csv; прямая запись File System Access на Chromium;
  автосохранение сессии и «Недавние».
- **Ключевые фичи ТЗ**: инкрементальный поиск (лист/книга, подсветка,
  счётчик), ПКМ-фильтрация по значению с чипами и «Показано N из M»,
  меню колонки ▾ (галочки значений, сортировка), кнопка Σ с карточкой метрик,
  Σ/n/x̄ в статус-баре по видимым строкам.
- **Формулы**: свой движок — 33 функции (SUM/SUMIF/SUMIFS, VLOOKUP,
  DATE-семейство и др.), живой инкрементальный пересчёт, автодополнение при
  «=», подсказки аргументов, ошибки человеческим языком, справочник «?» (F1)
  с живыми примерами; чужие формулы — кэш значения, ∛-индикатор, сохранение
  как есть.
- **PWA и мобильные**: офлайн-оболочка (precache), обновление по кнопке без
  потери сессии, мобильная раскладка (нижняя панель, крупные касания),
  длинное нажатие = ПКМ, пинч-зум таблицы, Ctrl+колесо, кнопки −/+.
- **Полировка v1.0** (Этап 6):
  - производительность: [docs/PERF-REPORT.md](PERF-REPORT.md) — метрики
    выделения на 100k ускорены 7.6×, фильтры не деградируют от ширины;
  - доступность: клавиатура везде (Shift+F10 — меню ячейки, стрелки в меню,
    фокус возвращается гриду), ARIA-разметка, живой регион активной ячейки,
    контраст WCAG AA по всем парам токенов (scripts/contrast-audit.mjs);
  - локализация: русский/английский интерфейс, переключатель в настройках;
    настройки: размер таблицы (масштаб ячеек/шрифта), разделитель CSV;
  - матрица платформ: e2e на Chromium + Firefox + WebKit (смок) и Android-
    эмуляции Pixel 7 (сценарий ТЗ касаниями без мыши); демо-файлы на стартовом
    экране.

## Публикация — готовность и решение владельца

**Приложение готово к публикации на GitHub Pages**, публикация заблокирована
не техникой, а планом GitHub: репозиторий приватный, Pages на бесплатном
плане для приватных репозиториев недоступен (риск 8 ROADMAP.md; карточка
novagrid-003 закрыта владельцем без включения Pages).

Что уже готово и не требует доработок:

- workflow [`.github/workflows/deploy-pages.yml`](../.github/workflows/deploy-pages.yml):
  сборка → проверка доступности Pages API → деплой; сейчас шаги деплоя
  корректно пропускаются с пометкой в логе;
- сборка с относительными путями (`base: './'`) — отдаётся и с подкаталога
  `https://<owner>.github.io/NovaGrid/`;
- PWA-манифест, иконки, сервис-воркер — установка и офлайн работают и на Pages.

**Решение владельца (одно из):**

1. перевести репозиторий в **public** (Settings → General → Danger Zone →
   Change visibility) — на бесплатном плане Pages станет доступен; затем
   Settings → Pages → Source: **GitHub Actions**. Деплой пойдёт автоматически
   на следующий пуш в main (или вручную: Actions → Deploy to GitHub Pages →
   Run workflow);
2. оплатить план GitHub Pro/Team — Pages доступен для приватного репозитория,
   действия те же;
3. оставить без публичного URL — приложение полностью работает локально
   (`npm run build` + `npm run preview`) и распространяется как PWA с любого
   статического хостинга.

После включения Pages публичный URL `https://<owner>.github.io/NovaGrid/`
считается публикацией v1.0 (КТ-5) — закрыть карточку novagrid-010, отметив
публикацию, или считать релиз состоявшимся по этой записи.
