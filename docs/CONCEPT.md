# NovaGrid — Концепция и требования

Версия: 1.0 (на согласование) · Дата: 2026-10-06 · Источник: `promt.txt` + проработка

---

## 1. Видение

**NovaGrid** — «революционно простая» программа для работы с таблицами.

Формула продукта: **открыл файл → нашёл → отфильтровал → сложил → сохранил** — за минуту,
без обучения, на любом устройстве.

- **Для кого:** все, кому Excel/Google Sheets кажутся избыточными: бухгалтеры, менеджеры,
  продавцы, домашние пользователи — любой, кому нужно посмотреть/посчитать таблицу, а не построить дашборд.
- **Чем отличается:** не пытается быть Excel. Убрано всё сложное (графики, макросы, сводные),
  зато ежедневные операции — поиск, фильтрация, суммирование — выведены на первый план и сделаны
  заметно удобнее, чем в больших редакторах.
- **Где работает:** Windows, macOS, Linux, Android, iPhone/iPad — одна программа (PWA), устанавливается
  из браузера, работает офлайн, аккаунт не нужен.
- **Приватность:** файлы не покидают устройство. Ни серверов, ни аналитики.

## 2. Принципы проектирования

| # | Принцип | Как проявляется |
|---|---------|-----------------|
| П1 | **Простота важнее полноты** | Никаких графиков, диаграмм, макросов, сводных. Каждая новая функция обязана проходить тест: «можно объяснить за 10 секунд?» |
| П2 | **Знакомые механики** | Выделение, Ctrl+C/V/Z, Ctrl+F — ведут себя как в привычных сервисах. Новое только там, где оно радикально удобнее (ПКМ-фильтр, кнопка Σ) |
| П3 | «Глазом и рукой» | Частотные действия — мышью в один жест: ПКМ по значению = фильтр, большая кнопка Σ = сумма выделенного |
| П4 | **Недеструктивность** | Фильтры скрывают строки, а не удаляют; правки обратимы (undo); автосохранение — ничего не теряется |
| П5 | **Помощь встроена в момент действия** | Справка по формуле появляется при вводе формулы; подсказки человеческим языком при ошибках |
| П6 | **Честные ограничения** | Если что-то не поддерживается (например, макросы) — пишем прямо, а не молча портим файл |
| П7 | **Скорость и лёгкость** | Большие файлы (100 000+ строк) открываются и листаются без лагов; приложение меньше 3 МБ |

## 3. Функциональные требования

Нумерация Ф1…Ф9 используется в ROADMAP и карте создания.

### Ф1. Файлы и листы

**Чтение (v1):**
- `.xlsx`, `.xlsm` (макросы не исполняются и не сохраняются — честная подпись при открытии);
- `.xls` — старый формат BIFF, включая многостраничные книги;
- `.csv`, `.tsv` — с автоопределением разделителя (`;`, `,`, таб) и кодировки (UTF-8, Windows-1251 и др.).

**Чтение (v2, после релиза):** `.ods`.

- Открытие: кнопка «Открыть», перетаскивание файла в окно, список «Недавние» на стартовом экране.
- Формулы в чужом файле: показываем последнее вычисленное значение (кэш файла); сама формула видна
  в строке формул. Пересчёт — для поддерживаемых функций (см. Ф6).
- Стили (жирность, цвета ячеек, форматы чисел) — читаются и сохраняются для .xlsx.

**Запись (v1):**
- «Сохранить» — в .xlsx (со стилями); на десктопных Chromium-браузерах Ctrl+S пишет прямо в открытый файл (File System Access API);
- «Сохранить как…» — .xlsx или .csv (активный лист);
- на iOS/Android и Firefox — сохранение через скачивание файла;
- автосохранение сессии: открытая книга и все правки восстанавливаются после закрытия/краша.

**Листы:** вкладки внизу — переключение, переименование, добавить, дублировать, удалить (с подтверждением при непустом).

### Ф2. Качественный поиск по листу и по всем листам

- Вызов: `Ctrl+F` или поле поиска в тулбаре. Поиск инкрементальный — результаты появляются по мере ввода.
- Режимы: **«Этот лист»** / **«Все листы»** (переключатель в панели поиска).
- Подсветка всех совпадений (мятный фон), текущее — оранжевая рамка + автопрокрутка к нему.
- Счётчик «12 / 47», навигация: `Enter` — вперёд, `Shift+Enter` — назад, `F3` — повторить поиск, `Esc` — закрыть.
- Опции (меню-«шестерёнка»): учитывать регистр, «ячейка целиком», искать в формулах.
- Умный поиск (novagrid-065): несколько слов в запросе — совпадение строка, где есть все
  слова (каждое — в любой ячейке строки, подсвечиваются ячейки со словами); «"фраза"» —
  точная фраза внутри одной ячейки; «-слово» — исключение; без учёта регистра Ё=Е.
  Одно слово — поиск подстроки; «ячейка целиком» и «найти и заменить» — буквальные.
- Режим «Все листы»: сгруппированный список результатов (Лист → совпадения с контекстом), клик — переход.
- Скорость: поиск по листу 100 000 строк ≤ 300 мс (поиск по видимым значениям, индексируется при загрузке).

### Ф3. Фильтрация правой кнопкой мыши (ключевая фича)

Сценарий из ТЗ: *«колонка 1 по фамилии Иванов, колонка 3 сумма 10000»* — двумя правыми кликами.

Механика:
1. **ПКМ по ячейке** → контекстное меню:
   - «**Фильтровать: колонка A = „Иванов"**» — строка действия, всегда первая;
   - «Исключить: A ≠ „Иванов"» (инверсия);
   - «Снять фильтр с колонки A» / «Сбросить все фильтры» — видны, когда есть активные фильтры;
   - Копировать ячейку / строку.
2. **ПКМ по другой ячейке той же колонки** при активном фильтре → «Добавить „Петров" к фильтру»
   (колонка принимает {Иванов, Петров}) или «Фильтровать только по „Петров"».
3. **ПКМ по ячейке другой колонки** → фильтр добавляется к существующим. **Несколько фильтров
   объединяются по «И»**: A = Иванов **И** C = 10000 — ровно сценарий из ТЗ.
4. **Чипы активных фильтров** — строка под тулбаром: `[A: Иванов ×] [C: 10000 ×] … [Сбросить всё]`.
   Крестик снимает один фильтр; клик по чипу — редактирование списка значений.
5. Статус: «Показано 132 из 1 500 строк». Фильтрация **недеструктивна** — строки скрываются, не удаляются.
6. Отфильтрованные колонки помечаются иконкой воронки в заголовке.
7. **Меню колонки** (кнопка ▾ в заголовке) — расширенный вариант: галочки значений с поиском,
   «(Пустые)», сортировка (см. Ф8) — для тех, кому привычнее классика.
8. **Мобильные:** то же меню открывается длинным нажатием на ячейку.

Значение для фильтра берётся **то, на котором нажали** — как сформулировано в ТЗ, без открытия диалогов.

### Ф4. Сумма — большая кнопка Σ и живые метрики

- **Большая кнопка Σ** закреплена в правой части тулбара, всегда на виду (фирменный оранжевый).
  Клик — карточка метрик текущего выделения: **Сумма**, Количество чисел, Количество заполненных,
  Среднее, Мин, Макс. Клик по строке — копирует значение в буфер.
- **Статус-бар** снизу дублирует главное всегда: `Σ 15 500 · n 12 · x̄ 1 291` — обновляется живьём при выделении.
- **Alt + выделение — мгновенная сумма** (идея из ТЗ): при зажатом Alt рамка выделения оранжевая,
  и сумма показывается **сразу крупно** в зоне кнопки Σ (и всплывающей меткой у курсора) — без единого клика.
- **Риск Alt:** на части систем Alt+перетаскивание перехватывается ОС/браузером (меню, перемещение окна).
  Митигция: (а) preventDefault закрывает большинство случаев — проверяем матрицей платформ на прототипе;
  (б) запасной путь — «липкий Σ-режим»: включил кнопку Σ — следующее выделение сразу показывает сумму.
  Решение фиксируется на спайке Этапа 1 (см. карту создания).
- Несмежные ячейки (Ctrl-выделение) суммируются как один массив (см. Ф5).

### Ф5. Выделение как в привычных сервисах + Ctrl-массивы

- Клик — ячейка; `Shift`+клик / `Shift`+стрелки — диапазон; **`Ctrl`+клик — несмежные ячейки
  объединяются в один массив**; `Ctrl`+перетаскивание — добавить диапазон; `Ctrl+A` — лист; `Esc` — снять.
- Все операции работают с объединением: Σ/метрики, копирование, очистка (`Delete`).
- Копирование несмежного выделения — по минимальному охватывающему прямоугольнику
  (пустые позиции — пустые), значения разделяются табами — вставляется в Excel/Google Sheets/блокнот.
- Визуал: активная ячейка — толстая зелёная рамка; выделение — полупрозрачный лайм;
  несмежные области — каждая со своей рамкой.

### Ф6. Формулы и доступная помощь

- Строка формул над таблицей: значение/формула активной ячейки, кнопка «fx».
- **Свой движок формул (v1, ~25 функций):** SUM, SUMIF, AVERAGE, AVERAGEIF, COUNT, COUNTA, COUNTIF,
  MIN, MAX, IF, IFS, AND, OR, NOT, CONCAT, LEFT, RIGHT, MID, LEN, TRIM, UPPER, LOWER, ROUND, ABS,
  DATE, TODAY, YEAR, MONTH, DAY, VLOOKUP (последние — ко второму релизу Этапа 4, см. карту).
- Пересчёт — живой: изменил аргумент — результат обновился.
- **Помощь в момент ввода:** начал писать `=su` → подсказка «SUM — сложить числа» с примером;
  внутри функции — подсказка аргументов `SUM(число1; [число2]; …)`.
- **Справочник «?»** в тулбаре: карточки формул (что делает, синтаксис, живой пример на текущей
  таблице), горячие клавиши, приёмы («как отфильтровать по двум колонкам»), список возможностей.
- **Ошибки человеческим языком:** не `#ERROR!`, а «Не хватает закрывающей скобки», «Диапазон A5:A2
  записан снизу вверх — нужно A2:A5».
- Совместимость: полная реализация Excel не ставится целью. При открытии чужого файла неподдерживаемая
  формула показывает последнее вычисленное значение с индикатором «∛ не пересчитывается» и сохраняется как есть.

### Ф7. Каркас книги и правки

- Undo/Redo: `Ctrl+Z` / `Ctrl+Y` — до 100 шагов, включая правки, вставки/удаления строк и колонок.
- Вставка/удаление строк и колонок (контекстное меню заголовков), ширина колонок (перетаскивание,
  двойной клик — авторазмер), закрепление строк/столбцов («Заморозить первую строку»).
- Режим вида «Колонки по тексту» (novagrid-067): все колонки сразу — по самому широкому
  тексту в них (потолок ~220 символов), включается/выключается в меню «Вид».
- Числовые форматы ячеек: общий, число, валюта (₽/$/€), процент, дата — из контекстного меню.
- Копирование/вставка значений и формул внутри книги и с буфером обмена ОС.
- Масштаб `Ctrl`+колесо (50–200%), полноэкранный режим.
- Автосохранение сессии (см. Ф1), стартовый экран: «Открыть файл», «Новая таблица», «Недавние».

### Ф8. Сортировка

- Меню колонки ▾: «По возрастанию / По убыванию» — с учётом текущего фильтра (сортируются видимые,
  скрытые строки остаются скрытыми), подтверждение при первом использовании («строки перемешаются,
  отменить можно Ctrl+Z»).

### Ф9. Локализация

- Интерфейс: **русский** (основной) + английский; переключатель в настройках; структура i18n заложена сразу.

## 4. Нефункциональные требования

| Категория | Требование |
|---|---|
| Производительность | Книга 100 000 строк × 30 колонок: открытие ≤ 3 с (парсинг в фоне), плавный скролл 60 fps, фильтр/поиск ≤ 300 мс |
| Платформы | Windows / macOS / Linux (Chrome, Edge, Firefox; Safari macOS), Android (Chrome), iPad/iPhone (Safari, PWA) |
| Офлайн | Полная работоспособность после первой загрузки; сервис-воркер кэширует оболочку |
| Хранение | Сессии и настройки — IndexedDB устройства; лимиты iOS Safari (~1 ГБ, evictable) учтены: подсказка «сохраните файл на диск» |
| Приватность | Ни одного сетевого запроса с данными; телеметрии нет; работает без аккаунта |
| Доступность | Полная клавиатурная навигация, ARIA-разметка грида, контраст WCAG AA, настраиваемый размер шрифта |
| Качество | Лицензии зависимостей только MIT / Apache-2.0 / BSD; CI: линт, типы, тесты, сборка |
| Размер | Приложение ≤ 3 МБ (без файлов пользователя) |

## 5. Анти-скоуп (что сознательно НЕ делаем в v1)

Диаграммы, графики, спарклайны · макросы/VBA · совместное редактирование и комментарии ·
сводные таблицы · условное форматирование правилами · проверка данных (валидация) ·
защита листов паролем · печать со сложной разбивкой (только печать браузером).

Всё перечисленное — кандидаты в v2 по итогам обратной связи, но не в первый релиз: простота — продукт.
