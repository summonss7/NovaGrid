## 1. Настроение и стиль

Светлый, чистый «SaaS»-минимализм: много воздуха, белые поверхности, скруглённые углы,
мягкие тени. Акценты — энергичные лайм-зелёный и оранжевый. Никакой визуальной пестроты:
цвет зарезервирован для действий (выделение, сумма, поиск) — таблица остаётся главной.

## 2. Палитра (токены)

Токены выровнены под WCAG AA (Этап 6.2, контраст-аудит `scripts/contrast-audit.mjs`):
текстовые роли и фон кнопок имеют собственные значения, декоративные рамки/иконки
достаточно 3:1 (порог UI-компонентов).

| Токен | HEX | Роль |
|---|---|---|
| `--nv-primary` | `#3ADF63` | лайм — выделение ячеек, активные состояния, логотип-стрелка |
| `--nv-primary-deep` | `#2BA84A` | зелёный — рамки/иконки (UI 3:1), декоративные элементы |
| `--nv-primary-text` | `#197530` | зелёный **как текст** (AA 4.5): логотип-слово, счётчики, ссылки |
| `--nv-primary-btn` | `#1E7D36` | фон главных кнопок — белый текст проходит AA (hover `#1A6E2F`) |
| `--nv-accent` | `#F26B21` | оранжевый — **кнопка Σ**, фокус поиска, текущее совпадение |
| `--nv-accent-deep` | `#E8481C` | внимание, hover оранжевого |
| `--nv-danger-text` | `#C23A10` | текст ошибок в ячейках (AA 4.5 на белом) |
| `--nv-ink` | `#2B2B2B` | основной текст |
| `--nv-ink-soft` | `#6B6B6B` | вторичный текст, подписи (AA на bg и surface) |
| `--nv-bg` | `#FFFFFF` | фон приложения |
| `--nv-surface` | `#EDEDEB` | панели, тулбар, заголовки строк/колонок таблицы |
| `--nv-mint` | `#E8F8EC` | фон чипов фильтра, **подсветка найденных ячеек** (тёмный штрих `#DFF5E3`) |
| линии сетки | `#E4E4E1` | границы ячеек |

Производные состояния:
- выделение ячеек: рамка `2px #3ADF63` + заливка `rgba(58,223,99,0.12)`;
- Alt-выделение (быстрая сумма): рамка `2px #F26B21` + заливка `rgba(242,107,33,0.10)`;
- активная (редактируемая) ячейка: рамка `2px #2BA84A`;
- найденные ячейки: фон `#E8F8EC`; текущее совпадение: дополнительно рамка `#F26B21`;
- отфильтрованная колонка: иконка воронки `#2BA84A` в заголовке.

Контраст: текст `#2B2B2B` на `#FFFFFF`/`#EDEDEB` — AA пройден; белый текст только на
`--nv-primary-deep` и `--nv-accent` (крупные элементы).

### 2.1. Тёмная тема (Этап 7.2)

Тёмный набор живёт в `tokens.css` под `:root[data-theme='dark']` — те же роли
и та же семантика, фирменные лайм/оранжевый остаются (роль зелёного-как-текста
и ошибок делают светлее ради AA). Незаданное наследуется у светлого набора.

| Токен | HEX (тёмная) | Отличие от светлой |
|---|---|---|
| `--nv-primary` | `#3ADF63` | без изменений (лайм) |
| `--nv-primary-deep` | `#3FCF6A` | ярче — рамки/иконки читаются на графите (UI 8.4:1) |
| `--nv-primary-text` | `#7FE39A` | светлее — зелёный как текст (AA 7.9–10.9 на bg/surface/mint) |
| `--nv-primary-btn` | `#1E7D36` | без изменений — белый текст проходит AA в обеих темах |
| `--nv-accent` | `#F26B21` | без изменений (кнопка Σ) |
| `--nv-accent-deep` | `#F2551F` | светлее — и hover Σ с белым (3:1), и текст ошибок строки формул (AA) |
| `--nv-danger-text` | `#FF8F6B` | тёплый светлый — AA 7.7 на bg |
| `--nv-ink` | `#E8EAE7` | светлые чернила (AA 10.3–14.2) |
| `--nv-ink-soft` | `#A7ADA8` | подписи (AA 6.5–7.5) |
| `--nv-bg` | `#191C1E` | графитовый фон приложения и ячеек |
| `--nv-surface` | `#24282B` | панели, тулбар, заголовки строк/колонок |
| `--nv-mint` | `#1D3A29` | тёмный мятный: чипы, подсветка найденного |
| `--nv-grid-line` | `#34393C` | границы ячеек |
| `--nv-hover` / `--nv-backdrop` | `rgba(255,255,255,.08)` / `rgba(0,0,0,.55)` | инвертированы относительно светлой |

Производные состояния: заливка выделения плотнее (`rgba(58,223,99,0.16)` — лайм
заметнее на графите), Alt-лассо `rgba(242,107,33,0.14)`, найденные ячейки
`#1D3A29`; тени глубже (чёрные, до 0.6), `color-scheme: dark` красит нативные
скроллбары и контролы.

**Механика.** Настройка «Тема: Система / Светлая / Тёмная» (диалог настроек,
персист в localStorage вместе с остальными настройками; `src/ui/theme.ts`).
`data-theme` ставится на `<html>` **inline-скриптом в `<head>` до первого
кадра** — сохранённая тёмная тема не вспыхивает светлым; дальше настройку ведёт
`useThemeSync`: «Система» резолвится через `prefers-color-scheme` (matchMedia)
и живьём реагирует на смену режима ОС. CSS-поверхности перекрашиваются токенами
сами; канвас-грид подписан на вычисленную тему и перечитывает токены
(`themeFromCSS`) с перерисовкой кадра — без перезагрузки страницы.
PWA: `meta theme-color` следует теме живьём (оболочка браузера/установленного
приложения), манифест перекрашивается лучшим усилием (blob-копия с нужным
`theme_color`; при офлайне тихо пропускается).

Контраст обеих тем проверяется одним прогоном:
`node scripts/contrast-audit.mjs` — два прохода (светлая + тёмная), пороги AA
те же (4.5:1 текст, 3:1 крупный/UI).

## 3. Типографика

| Роль | Шрифт | Начертание |
|---|---|---|
| Логотип, заголовки, кнопки | **Montserrat** | 600/700 |
| Таблица, интерфейс, текст | **Open Sans** | 400/600 |

Размеры: базовый UI 14 px; таблица 13–14 px; заголовок окна 18–20 px; кнопка Σ — 20 px символ.
Шрифты self-hosted (woff2, только нужные подмножества) — офлайн и быстрый первый запуск.

## 4. Форма и глубина

- Радиусы: 8 px — кнопки и поля; 12 px — панели, карточки, выпадающие меню.
- Тени: мягкие `0 2px 8px rgba(43,43,43,0.08)`; у выпадающих меню `0 8px 24px rgba(43,43,43,0.14)`.
- Иконки: lucide, тонкие (1.5 px), чернильные; в цвете — только смысловые (воронка фильтра, Σ).

## 5. Логотип

Знак **«сфотографированная ячейка»** (модернизация знака «ячейка с продолжением линий»
по пожеланию владельца, novagrid-031, 15.10.2026): кадр «фотографии» вырезал из таблицы
одну ячейку — на чёрной скруглённой плитке остался **зелёный контур выделения**
(штрих 6/48, ячейка пустая внутри, сторона 23,4/48 — на 30 % крупнее прежней заливки),
а из углов кадра торчат **короткие оранжевые обломки линий соседних ячеек** (штрих 6/48,
круглые торцы): под рамкой лежит оранжевая сетка из четырёх линий по координатам рёбер
ячейки, чёрная заливка рамки прикрывает их середины — на виду только восемь лучей у углов.
Смысл: выделенная ячейка живёт в целой таблице, продолжающейся за краем кадра; контур —
тот же жест, что рамка выделения ячейки в самом приложении. Линии нарочно толстые,
чтобы знак читался в иконках от 16 px. Слева в тулбаре: знак + слово NovaGrid
(Montserrat 700, «Nova» чернильным, «Grid» `--nv-primary-text`).
SVG-версия знака: `src/ui/Logo.tsx` (компонент) и `public/favicon.svg` — источник
растеризации иконок PWA и десктоп-оболочки (`scripts/make-icons.mjs`,
`scripts/make-desktop-icons.mjs`): 192/512 и .ico — плитка с прозрачными углами,
maskable и apple-touch — full-bleed чёрный под маску лаунчера.

## 6. Раскладка главного окна (десктоп)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [N] NovaGrid │ Открыть  Сохранить │ [🔍 Поиск…  Ctrl+F]        [?]  │ тулбар
│                                      ┌──────────────────────────┐    │
│                                      │        Σ  СУММА          │    │ большая кнопка
│                                      └──────────────────────────┘    │ (оранжевый)
│ Фильтры:  [A: Иванов ×]  [C: 10 000 ×]               Сбросить всё    │ чипы (появляются)
│ fx │ =SUM(C2:C14)                                                     │ строка формул
│ ───┬──────────┬──────────┬──────────┬──────────┬─────────────────── │
│    │    A ▾   │    B     │    C ▾   │    D     │      …             │ заголовки (surface)
│  1 │ Иванов   │ …        │ 10 000   │          │                    │
│  2 │ Петров   │ …        │ 12 500   │          │                    │ канвас-грид
│  … │ …        │          │          │          │                    │ (виртуализация)
│ ───┴──────────┴──────────┴──────────┴──────────┴──────────────────── │
│ [Лист 1] [Данные ×] [+]          Показано 132 из 1 500              │ панель листов
│                                    Σ 22 500 · n 2 · x̄ 11 250        │ статус-бар метрик
└──────────────────────────────────────────────────────────────────────┘
```

- Тулбар слева-направо: лого, Открыть, Сохранить, разделитель, поиск, справка `?`;
  **справа, всегда на виду — большая кнопка Σ** (56 px, оранжевая, с подписью «СУММА»).
- Карточка Σ при клике: Сумма / Кол-во чисел / Кол-во заполненных / Среднее / Мин / Макс —
  клик по строке копирует значение.
- Alt-выделение: сумма появляется крупно над кнопкой Σ и меткой у курсора.

## 7. Контекстное меню ПКМ (ключевой жест)

```
┌────────────────────────────────────┐
│ 🔽 Фильтровать: A = «Иванов»       │  ← строка-действие, выделена
│    Исключить: A ≠ «Иванов»         │
│ ────────────────────────────────── │
│    Снять фильтр с колонки A        │  ← виден при активном фильтре
│    Сбросить все фильтры            │
│ ────────────────────────────────── │
│    Копировать ячейку               │
│    Копировать строку               │
└────────────────────────────────────┘
```

При повторном ПКМ в той же колонке: «Добавить «Петров» к фильтру» / «Фильтровать только по «Петров»».

## 8. Панель поиска

Поле в правой части тулбара, раскрывается по `Ctrl+F`: переключатель «Этот лист / Все листы»,
счётчик «12/47», ▲▼ навигация, «шестерёнка» опций (регистр, ячейка целиком, в формулах).
В режиме «Все листы» под полем — выпадающий список результатов, сгруппированный по листам.

## 9. Мобильная раскладка

- Верх: тонкая строка (лого, имя файла, меню-«⋯»).
- Низ: панель действий **Открыть · Σ · Поиск · ?** (большие касания ≥ 48 px).
- Чипы фильтров — горизонтальная лента под верхом.
- ПКМ заменён длинным нажатием (то же меню); выделение — касанием и перетаскиванием;
  метрики выделения — крупная плашка над нижней панелью.
- Строка формул сворачивается (раскрытие по касанию адреса ячейки).

## 10. Панель помощи «?»

Правая боковая панель: разделы «Формулы» (поиск + карточки: назначение, синтаксис, живой пример
на текущей таблице), «Горячие клавиши», «Возможности», «Приёмы» (мини-инструкции, в т.ч.
«фильтрация по нескольким ячейкам» из сценария ТЗ).
