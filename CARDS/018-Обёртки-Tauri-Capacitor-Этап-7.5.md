## Задача
Этап 7.5 плана доработки (карточка novagrid-014): нативные обёртки из бэклога Этапа 7
(docs/CREATION-MAP.md: «Tauri/Capacitor обёртки»). Приложение уже PWA — обёртки дают
значок в меню «Пуск», автозапуск и файловые ассоциации .xlsx/.csv без браузера.

Приоритет веток: Tauri 2 (десктоп Windows) — основной этап; Capacitor (Android APK) —
только если Tauri-ветка закрыта быстро и инструментальная база Android уже стоит
(сборка APK всегда в builds/ с версией и типом debug/release). Если тулчейн не
ставится в этой среде — не форсировать: зафиксировать в docs/WRAPPER.md протокол
сборки для машины владельца и поставить карточке status: blocked с причиной в журнале.

Состав (Tauri-ветка):
1. Каркас обёртки: packages/desktop (или desktop/ по структуре репозитория) —
   tauri.conf.json (окно 1280×800, минимальный размер, фирменные иконки из
   scripts/make-icons.mjs, product name NovaGrid), Rust-каркас минимальный.
2. Интеграция: обёртка грузит production-сборку (npm run build → dist);
   dev-режим — vite devserver; конфиг сборки в package.json (npm run desktop:build).
3. Фичи оболочки: файловые ассоциации (.xlsx/.csv/.xls/.ods — открыть в приложении),
   меню «Файл» (Открыть/Сохранить как) через нативный диалог, внешние ссылки —
   в системном браузере.
4. Артефакты: сборки .exe/.msi класть в builds/ с версией и типом
   (например builds/novagrid-1.5.0-setup-release.exe); builds/ в .gitignore,
   в отчёте — путь и размер.
5. Документация: docs/WRAPPER.md (как собрать на Windows: пререквизиты Rust/VS Build
   Tools, команды), README (раздел «Десктоп-приложение»), ROADMAP/CREATION-MAP.

Готово, когда: на этой машине собирается установщик в builds/ (версия+тип в имени),
приложение открывает книгу drag-and-drop и через «Файл → Открыть», или — если среда
не позволяет — карточка blocked с полным протоколом сборки в docs/WRAPPER.md.
Один этап — одна сессия: за пределы этапа не выходи, следующий этап не начинай.
