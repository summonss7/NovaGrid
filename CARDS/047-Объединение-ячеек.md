## Задача
Добор Excel-базиса, шаг 1 из 5 (решение Артёма по novagrid-046: «всё по порядку — по карточке
на сессию»). Объединение ячеек выделенного диапазона как в Excel: кнопка «Объединить» в
FormatBar и/или пункт контекстного меню; значение остаётся в левой верхней ячейке, остальные
очищаются (при потере данных — предупреждение), «Разъединить» возвращает обычные ячейки.
Модель merges (список прямоугольников) в листе; рендер объединённой ячейки одной областью
(текст/стиль левой верхней); выделение, клавиатурные переходы, правка, копирование,
фильтры и поиск не попадают в скрытые ячейки; вставка/удаление строк-колонок сдвигает merges
(remap как у формул, с #REF!-логикой ссылок на скрытое не требуется — ссылки остаются валидными);
одна транзакция Ctrl+Z. Импорт mergeCells из .xlsx/.ods при открытии файла. Сохранение
объединений в файл — в novagrid-050, здесь не делать.

## Критерии готовности
- [ ] Объединить/разъединить диапазон из UI (FormatBar и/или ПКМ), Ctrl+Z откатывает; при потере данных — предупреждение
- [ ] Грид рисует объединённую ячейку одной областью; ввод, Tab/Enter, выделение и копирование не заходят в скрытые ячейки
- [ ] Вставка/удаление строк-колонок корректно сдвигает/режет merges; фильтры, поиск и протяжка выделением не ломаются
- [ ] Открытие .xlsx/.ods с объединёнными ячейками показывает их объединёнными
- [ ] Юнит-тесты модели/сдвигов/рендера проходят; e2e не сломаны (+ новые на объединение)
