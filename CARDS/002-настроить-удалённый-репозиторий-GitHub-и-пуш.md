## Задача
Правила проекта требуют после каждой задачи коммит и пуш на GitHub. Локальный git-репозиторий
уже создан (ветка main), но: gh CLI не установлен, remote не настроен, адрес репозитория неизвестен.

Требуется (с участием владельца):
1. Создать репозиторий на GitHub (например, `summonss7/NovaGrid`).
2. Либо установить и авторизовать `gh` CLI, либо дать URL репозитория для `git remote add origin`.
3. Настроить push (credential manager) и выполнить первый пуш существующей истории.
4. (Опционально, вместе с Этапом 0) включить GitHub Actions для CI и GitHub Pages.

## Критерии готовности
- [ ] remote origin настроен и `git push` проходит без ошибок
- [ ] вся локальная история запушена на GitHub
- [ ] способ пуша задокументирован в README (раздел «Как ведётся работа»)
