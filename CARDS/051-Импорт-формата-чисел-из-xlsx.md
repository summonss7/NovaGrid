## Задача
Добор Excel-базиса, шаг 5 из 5 (решение Артёма по novagrid-046: «всё по порядку — по карточке
на сессию»). При открытии .xlsx читать числовой формат ячейки (numFmt) и маппить на наши fmt
(Общий/Числовой/Валютный ₽/Процентный): '#,##0*' → Числовой; '0.*%' → Процентный; валютные
(₽/$/€ в формате) → Валютный; прочее → Общий. Неизвестные/экзотические форматы не ломают
импорт (безопасный fallback). .ods — по возможности (числовые стили ячеек), иначе Общий.
После импорта формат виден в гриде и в панели форматирования как назначенный пользователем.

## Критерии готовности
- [x] Открытие .xlsx с ячейками в числовом/валютном/процентном форматах отображает их теми же форматами
- [x] Неизвестные numFmt безопасно дают Общий, импорт не падает
- [x] .ods: импорт числовых стилей по возможности, без падений
- [x] Юнит-тесты маппинга numFmt → fmt проходят; e2e не сломаны
