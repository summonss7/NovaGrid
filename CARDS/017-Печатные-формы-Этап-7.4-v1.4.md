## Задача
Этап 7.4 плана доработки (карточка novagrid-014): печатные формы из бэклога Этапа 7
(docs/CREATION-MAP.md). Границы скоупа — печать браузером (анти-скоуп CONCEPT §5
«печать со сложной разбивкой» не трогаем: без масштабирования по страницам Excel-класса).

Состав:
1. Печатный рендер: канвас не печатается — собрать печатный DOM по модели книги
   (таблица видимых строк с учётом фильтров и ширин колонок, заголовки колонок/строк),
   показать его только в @media print; тулбар/панели/чипы/диалоги/мобильная панель
   на печати скрыты.
2. Настройки печати в приложении (перед window.print()): «что печатать» —
   текущий лист видимыми строками (по умолчанию, с чипами фильтров в колонтитуле)
   или весь лист; ориентация альбомная по умолчанию; формат A4/Letter.
   Настройки — в диалоге печати, вызов: Ctrl+P и пункт в меню «⋯».
3. Числа/даты печатаются форматом текущей локали; повтор заголовка колонок
   на каждой странице (thead repeat), тонкие линии сетки, шрифт печатный
   (без веб-шрифтов тяжёлых весов).
4. Тесты: юнит на сборку печатного DOM (фильтры, ширины, пустые); e2e с
   Playwright media="print" (emulated media) — печатная страница содержит данные
   и не содержит тулбара; сценарий ТЗ: фильтр «Иванов+10000» → печать показывает
   отфильтрованные строки.
5. Документация: README (раздел «Печать»), ROADMAP, CREATION-MAP.

Готово, когда: Ctrl+P из приложения даёт чистую печатную страницу с данными
(учёт фильтров, повтор шапки), UI на печати скрыт, проверки зелёные, версия 1.4.0.
Один этап — одна сессия: за пределы этапа не выходи, следующий этап не начинай.
