## Задача
Второй этап мобильной версии (зонтичная novagrid-057): инфраструктура одновременной
поддержки платформ — «меняется что-то → во всех версиях». Опора на этап 1 (novagrid-058).

Конкретика:
- scripts/android-build.sh по образцу desktop-build.sh: сборка release APK в
  builds/novagrid-<версия>-android-release/ (+ apk), проверка синхронности версий
  package.json / tauri.conf.json / tauri.android.conf.json / Cargo.toml;
- npm-скрипты android:dev / android:build (+ android:icons при необходимости);
- dev-режим на эмуляторе (tauri android dev) — описание в WRAPPER.md;
- README.md: матрица платформ (веб/PWA, Windows, Android; iOS — подготовка),
  как получить Android-версию;
- docs/WRAPPER.md: раздел Android (тулчейн: SDK/NDK/JDK, env ANDROID_HOME/NDK_HOME/
  JAVA_HOME, rust-таргеты, gen/android, сборка, live-check на эмуляторе);
- ROADMAP.md отражает новую платформенную линию;
- полный прогон: unit / typecheck / lint / e2e, сборка десктоп + android в одних
  версиях — конвейер «одно изменение → все платформы».
