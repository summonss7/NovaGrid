## Задача
Добор Excel-базиса, шаг 2 из 5 (решение Артёма по novagrid-046: «всё по порядку — по карточке
на сессию»). Кнопка «Перенос текста» в FormatBar по выделению (поле wrap в CellStyle, как
align/fmt). Рендер: текст переносится по словам по ширине колонки, высота строки
авто-растёт под число строк (как в Excel), вертикальное выравнивание — по верху; сочетается
с выравниванием, форматом числа и стилями; изменение ширины колонки и масштаба пересчитывает
перенос и высоту; одна транзакция Ctrl+Z. Автовысота не должна конфликтовать с ручной
высотой строк (если она есть — по спайку решения). Сохранение переноса в файл — в novagrid-050.

## Критерии готовности
- [ ] Кнопка переноса текста в FormatBar работает по выделению, Ctrl+Z откатывает
- [ ] Длинный текст переносится по словам по ширине колонки, высота строки растёт под число строк
- [ ] Смена ширины колонки/масштаба пересчитывает перенос и высоту; формат числа, выравнивание и стили сочетаются с переносом
- [ ] Юнит-тесты (модель wrap, расчёт строк/высоты) проходят; e2e не сломаны (+ новые)
