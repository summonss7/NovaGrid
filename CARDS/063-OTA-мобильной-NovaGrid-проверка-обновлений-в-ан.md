## Задача
Мобильная NovaGrid (android-обёртка novagrid-058..060, v1.29.0) не умеет проверять
обновления — APK в «Скачать» хаба Aila приходится ставить вручную. Пожелание Артёма
(aila-370, 07.11.2026): «нужно ещё добавить систему автообновления так как это работает
по всем проектам». Единая система семьи — центр обновлений Aila (концепция
D:\Scheduler\UPDATES-SYSTEM.md): манифест v2 `GET /updates/novagrid/manifest.json`,
эталон клиента — UpdateManager LeCards (lecards-025). Канал novagrid уже существует
(в нём 1.29.0, но только windows-файлы — android-asset не публиковался).

Сделать в android-обёртке (desktop/, мобильная ветка):
- тихая проверка манифеста при старте (не чаще раза в 10 минут по персистентной метке —
  образец lecards-027) + явная кнопка «Проверить обновления» в мобильном UI;
- сравнение версий: versionName (semver) с версией сборки; из assets выбирать android-файл
  (.apk; фильтр по имени/abi, у нас universal aarch64);
- баннер «⬆ Доступна версия X» + notes («что нового»), «✓ У вас последняя версия» —
  явно и по кнопке, и после тихой проверки;
- скачивание APK в temp с прогрессом и сверкой sha256, затем системная установка
  (intent application/vnd.android.package-archive;PermissionRequest на установку
  неизвестных — Android сам спросит);
- Aila недоступна — молча работаем как есть («не удалось проверить» — не ошибка).
- публикация релиза с APK: кнопка 🚀 в «Скачать» хаба Aila уже умеет (aila-163) —
  в манифест канала должен попасть и android-файл (проверить, что он в списке сборок
  версии и публикуется вместе с windows-файлами).

Правила проекта (обязательны): как в шапке AGENTS.md — бэкап перед правками, тесты
после, сборки в builds/ с версией и типом, CHANGELOG с датой начала/окончания, коммит
с пушем, отчёт Артёму в «Хаб ИИ». Живая проверка мобильного UI — на эмуляторе
(adb-тапы + CDP, как novagrid-058).

## Критерии готовности
- [ ] Тихая проверка манифеста при старте (не чаще 10 мин, персистентная метка) + кнопка «Проверить обновления»
- [ ] Баннер «⬆ Доступна версия X» с notes и «✓ У вас последняя версия» — оба состояния видны
- [ ] Скачивание APK с прогрессом, сверка sha256, системная установка через intent
- [ ] Недоступность Aila не ломает приложение (тихая деградация)
- [ ] В канал /updates/novagrid опубликован релиз, в манифесте которого есть android-asset (APK)
- [ ] Живая проверка на эмуляторе: баннер при старой версии, установка новой, «последняя версия» после
- [ ] Юнит-тесты проекта зелёные (+ новые на логику выбора asset/сравнения версий)
- [ ] CHANGELOG.md дополнен (дата-время начала/окончания), коммит с пушем
- [ ] README/docs (WRAPPER.md) отражают OTA мобильной ветки
