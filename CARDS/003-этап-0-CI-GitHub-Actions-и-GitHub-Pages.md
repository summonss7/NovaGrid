## Задача
Опциональный пункт карточки novagrid-002, отложенный до Этапа 0 «Фундамент» (ROADMAP).
Репозиторий https://github.com/summonss7/NovaGrid уже существует и настроен (remote origin, пуш работает).

Требуется (когда появится код/каркас — Этап 0):
1. Создать workflow GitHub Actions: линт + тесты + сборка на каждый пуш в main и PR.
2. Настроить GitHub Pages для деплоя сборки (ветка/gh-pages или Actions-деплой).
3. Учесть, что репозиторий сейчас приватный: Pages на приватном репозитории требует
   платного плана GitHub — при необходимости согласовать с владельцем переключение
   репозитория в public (запланировано на КТ-5, v1.0) или использование плана.

## Критерии готовности
- [ ] workflow CI в .github/workflows запускается и зелёный на пуше в main
- [ ] GitHub Pages отдаёт собранное приложение по публичному URL
- [ ] способ деплоя задокументирован в README (раздел «Как ведётся работа»)
